# Alice Family Tasks

Пользовательская интеграция, созданная Domologic (www.domologic.ru) для Home Assistant. Трекер семейных задач, создаваемых голосом через приватный навык Алисы. Задачи членам семьи выводятся на дашборд HA.

Получатели не зашиты в код. В настройках можно создать любое количество получателей, указать отображаемое имя, голосовые алиасы и связать каждого с отдельным `todo`-списком Home Assistant.

## Возможности

- произвольное количество получателей и алиасов;
- фразы вроде `Диме взять форму завтра`, `маме позвонить врачу 12 сентября`, `всем закрыть окна`;
- даты `сегодня`, `завтра`, `послезавтра`, дни недели и календарные даты;
- компактная Lovelace-карточка с адаптивными колонками;
- выполнение задачи нажатием на строку;
- удаление выполненных задач после полуночи;
- webhook для Yandex Cloud Function и действия для автоматизаций Home Assistant.

## Установка через HACS

1. В HACS откройте **Интеграции** и добавьте этот репозиторий как пользовательский репозиторий типа **Integration**.
2. Установите **Alice Family Tasks** и перезапустите Home Assistant.
3. Откройте **Настройки -> Устройства и службы -> Добавить интеграцию** и выберите **Alice Family Tasks**.
4. Добавьте первого получателя, затем через **Настроить** добавьте остальных.

Для каждого получателя заранее нужен список из интеграции **Local to-do**.

## Карточка Lovelace

Добавьте ресурс JavaScript:

```text
/alice_family_tasks/alice-family-tasks-card.js
```

Тип ресурса: `JavaScript Module`.

Затем добавьте карточку:

```yaml
type: custom:alice-family-tasks-card
entity: sensor.aktualnye_zadachi
show_completed: true
```

Точный `entity_id` итогового сенсора можно посмотреть на странице интеграции.

## Алиса через Home Assistant

Если в Home Assistant уже есть endpoint `/api/yandex_dialogs`, укажите его внешний HTTPS-адрес как **Webhook URL** приватного навыка. Интеграция слушает событие `yandex_intent`, добавляет задачу и возвращает Алисе ответ через `yandex_intent_response`.

Отключите прежние автоматизации, которые слушают то же событие, иначе одна команда будет обработана дважды.

## Алиса через Cloud Function

В корне репозитория лежит `index.py` для Yandex Cloud Functions. Создайте функцию Python 3.12, укажите точку входа `index.handler` и переменную окружения:

```text
HA_WEBHOOK_URL=https://ваш-внешний-ha/api/webhook/секретный-id
```

Путь webhook отображается в атрибуте `webhook_path` сенсора интеграции. В Яндекс Диалогах выберите созданную функцию backend приватного навыка.

## Действия

- `alice_family_tasks.process_command` принимает исходную голосовую фразу;
- `alice_family_tasks.add_task` принимает получателя, текст и необязательную дату.
