# Changelog

## 0.1.1

- Карточка гарантированно обновляется после полуночной очистки выполненных задач.
- Документация дополнена прямым подключением Яндекс Диалогов к Home Assistant.

## 0.1.0

- Настраиваемое количество получателей, имена и голосовые алиасы.
- Разбор относительных дат, дней недели и календарных дат на русском языке.
- Webhook и адаптер для приватного навыка Алисы.
- Адаптивная Lovelace-карточка с выполнением задач нажатием.
- Автоматическая очистка выполненных задач после полуночи.
